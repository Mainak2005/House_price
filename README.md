# 🏠 California Housing Price Prediction using Machine Learning

## 📘 Project Overview

This project focuses on predicting house prices in California using the **California Housing Dataset**. The goal is to build and evaluate machine learning models that can estimate housing prices based on factors such as median income, population, and geographic location.

## 🧠 Objective

To analyze housing data and create a predictive model that provides accurate insights into real estate pricing trends across California.

## 📊 Dataset

* **Source:** California Housing Dataset (available in `sklearn.datasets`)
* **Features include:**

  * Median Income
  * House Age
  * Average Rooms
  * Average Occupancy
  * Latitude & Longitude
  * Median House Value (Target Variable)

## ⚙️ Steps Involved

1. **Data Collection:** Imported dataset from Scikit-learn library.
2. **Data Preprocessing:** Handled missing values, normalized data, and encoded features.
3. **Exploratory Data Analysis (EDA):** Visualized correlations and feature importance.
4. **Model Building:** Implemented regression models including:

   * Linear Regression
   
5. **Model Evaluation:** Compared models using metrics such as:

   * Mean Squared Error (MSE)
   * Root Mean Squared Error (RMSE)
   * R² Score

## 🚀 Results

* The Random Forest model achieved the highest accuracy among all tested models.
* Median income and location (latitude & longitude) were the most significant predictors of housing prices.

## 📈 Conclusion

The project successfully demonstrates how machine learning can be used to predict housing prices with high accuracy. It provides valuable insights into the relationship between socioeconomic and geographical factors and real estate values.
